## Checked and left alone

- Identity: usage location before licensing, dynamic groups needing Entra ID P1, role-assignable groups being fixed at creation, and the effect of a directory change on role assignments.
- Governance: RBAC inheritance and its additive model, deny assignments, lock behaviour, policy evaluation triggers, remediation tasks with managed identities, and budgets never stopping resources.
- Moves: both groups locked for up to four hours, children moving with the parent, and Resource Mover for region moves.
- Storage: redundancy options, access tiers, customer-managed keys needing soft delete and purge protection, infrastructure encryption chosen at creation, Azure Files identity sources, and AzCopy needing a data role.
- Compute: changing a disk type requires deallocating the VM (q15), encryption at host prerequisites, App Service tier features, and Container Apps and Container Instances scaling and restart policies.
- Networking: the 5 reserved addresses per subnet, NSG processing order, peering being non-transitive, the Basic public IP and Basic Load Balancer retirement (September 30, 2025), NSG flow log retirement (September 30, 2027), and Bastion SKUs.
- Monitoring and recovery: alert processing rules, the two vault types, retention behaviour of backup policy changes, metric and Activity log retention, and Site Recovery recovery points and test failover.
