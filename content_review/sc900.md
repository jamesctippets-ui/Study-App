New track, written and checked on 2026-11-09 against the SC-900 study guide "Skills measured as of October 21, 2026" and the four Microsoft Learn learning paths for the exam. The outline weights are concepts 10–15%, Microsoft Entra 25–30%, security solutions 35–40% and compliance solutions 20–25%. The track's category marks are 13 / 27 / 37 / 23.

## Built

- Four categories mirror the four skills areas, and the lessons walk the study guide in order: security and compliance concepts, identity concepts, Entra identities, Entra authentication, Entra access and governance, Azure infrastructure security, Defender for Cloud, Sentinel, Defender XDR, Service Trust Portal and Compliance Manager, information protection and lifecycle, then insider risk, eDiscovery and audit.
- Every bullet of the October 2026 outline has at least one flashcard and one question.
- The 2026 changes noted in the study guide's change log (Entra identity types, Defender XDR) are covered: workload identities and Entra Agent ID, and Defender Vulnerability Management, Microsoft Threat Intelligence and the Defender portal.
- Facts checked against Microsoft Learn on 2026-11-09:
  - Entra ID Free, P1 and P2 feature split, and that risk-based Conditional Access and PIM need P2;
  - the DDoS Protection tiers (infrastructure, IP Protection, Network Protection);
  - Azure Firewall Basic, Standard and Premium feature split (TLS inspection, IDPS and URL filtering are Premium);
  - Foundational CSPM (free) against the paid Defender CSPM plan;
  - Purview Audit retention (Standard 180 days, Premium one year by default, up to 10 years with an add-on);
  - that Sentinel leaves the Azure portal after March 31, 2027.

## Checked and left alone

- Shared responsibility is stated only where it does not vary: data, devices and identities always the customer, the physical layer always Microsoft, the operating system depending on IaaS, PaaS or SaaS. The per-model cells for network controls and applications were left out on purpose.
- Passkey wording follows the Entra pages, which now call the method "passkey (FIDO2)".
- Defender for Cloud Apps and Defender for Cloud are kept apart in cards, questions and a compare pair, because the names are the most common look-alike trap.

## Needs a human check

- Exam length is given as 50 questions in 45 minutes. Microsoft says Fundamentals exams run 45 minutes and most exams have 40 to 60 questions, but the exam page itself did not load, so the exact question count for SC-900 is not confirmed. Check the exam details in your Pearson VUE or Learn profile before an exam date.
- Entra Agent ID (f63, tf23) is included because the October 2026 change log marks the identity types objective as a minor change. The study guide's wording for that change was not visible, so confirm whether agent identities are actually examined. Conditional Access for agents needs a Microsoft Agent 365 license according to the licensing page.
- The Sentinel Azure-portal retirement date (after March 31, 2027) appears in f137, q136, the Sentinel lesson and the cheat sheet. Microsoft has moved this date before (it was July 2026), so re-check it.
- Microsoft Priva is in the title of the Purview Learn path and has a short card (f203), but the outline's Service Trust Portal section lists only the portal and the privacy principles.
- Microsoft Purview data governance (f237) has one light card. The study guide lists data governance in a heading with no bullets under it, so check whether any questions now cover the Unified Catalog.
- The Defender CSPM feature list (attack path analysis, agentless scanning, governance, regulatory compliance) moves between the free and paid plans over time. Compare f122 and q123 with the current Defender for Cloud plan table before an exam.
- Defender for Office 365 Plan 1 against Plan 2 (f150, q144) and Azure Firewall web categories (Standard and Premium) were taken from product pages that Microsoft revises often.
- No screenshots or Playground labs exist for this track, and no lesson has a diagram. A screenshot of the Defender portal or the Purview portal would need a CC BY source or a screenshot taken by James.
